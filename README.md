# dsh-artifacts-panel — 产物面板

![license](https://img.shields.io/badge/license-MIT-blue) ![version](https://img.shields.io/badge/version-0.4.0-blue)

一个 DeepSeek Harness（`dsh`）Web 插件：在工作区里扫描「产物」文件（Agent 生成的各类文件），
并按 **类型 / 日期 / 体积 / 行数** 分组与排序展示。面板**嵌入窗口右侧的详情栏**（`details` 插槽），
随会话切换自动跟随当前工作目录。

## 功能

- **右侧嵌入**：面板常驻窗口右侧详情栏，切换会话时自动跟随该会话的工作目录；
  右上角「✕」或拖拽栏可收起。收起后，窗口**右下角贴边的「📦 产物面板」标签**可重新打开——
  标签吸附窗口边缘、无阴影、使用窗口边框与底色主题令牌，与 DSH 窗口外观融为一体；
  详情栏打开时标签自动隐藏，不遮挡面板内容。
- **目录选择**：默认扫描当前会话的工作目录，也可下拉切换任意已注册工作区。
- **搜索过滤**：头部搜索框按文件名 / 路径实时过滤（大小写不敏感），统计与分组随之更新。
- **子目录下钻**：面板顶部「子目录」区列出当前目录的直接子目录，点击即进入重新扫描；「⬆」返回上级。
- **手动路径扫描**：输入绝对路径 + 回车扫描任意目录（`scope: any` 时可用）。
- **状态记忆**：分组 / 排序 / 升降序 / 自动刷新 / 上次目录持久化到 localStorage，刷新页面后自动恢复。
- **长列表分页**：默认渲染 200 条，底部「显示更多」逐批展开，5000 文件也不卡。
- **文件预览抽屉**：点击文件行打开预览视图（受 `maxPreviewBytes` 上限，超出截断提示；**图片文件（png/jpg/gif/webp/bmp/ico/avif/tiff）直接渲染预览**，其余二进制标记不可预览），预览头部可复制完整路径、返回列表。
- **Agent 工具**：注册 `artifacts_list` 工具，DSH Agent 可直接「列出/统计」工作区产物（可选目录/关键字过滤/扫描上限），遵守同样的 scope 安全规则。
- **四种分组**：
  - 按类型：代码 / 文档 / 配置 / 数据 / 图片 / 媒体 / 前端资源 / 归档 / 其他
  - 按日期：今天 / 昨天 / 近 7 天 / 近 30 天 / 更早
  - 按体积：≤1KB / 1–10KB / 10–100KB / 100KB–1MB / >1MB
  - 按行数：无行数（二进制）/ ≤10 / 11–100 / 101–1000 / >1000
- **四种排序**：名称 / 体积 / 行数 / 日期，升序或降序。
- **统计信息**：每组文件数与体积合计，面板头部显示文件总数与总体积。
- **元数据**：每行显示类型色点、文件名、行数、体积、修改时间；点击行打开预览抽屉（复制路径在预览头部）。
- **自动刷新**：可选 60 秒自动重新扫描。
- **安全默认**：`scope: workspace` 时，HTTP 路由只允许扫描已注册工作区及其子目录；
  二进制文件与超大文件不统计行数；预览读取受大小上限约束；自动跳过 `node_modules`、`.git`、`dist` 等目录。

> 注意：面板占用右侧详情栏（`details` 插槽，priority -1），会覆盖官方默认的「工具调用详情」面板；
> 这是原生右侧栏的唯一挂载点，与社区同类插件（如 DSH-Right-Sidebar）的做法一致。

## 安装

```sh
cd dsh-artifacts-panel
dsh plugin --profile web add .
```

或从插件目录以 `file:` 形式安装：

```sh
dsh plugin --profile web add "file:$(pwd)"
```

安装完成后**重启 `dsh web`**（客户端 bundle 与宿主路由在启动时装载）。

## 使用

1. 重启后，产物面板直接显示在窗口**右侧详情栏**（默认开启）。
2. 默认扫描当前会话工作目录；可在下拉框切换到其他工作区，或点顶部「子目录」区进入下一级，用「⬆」返回上级。
3. 在搜索框输入关键字实时过滤；输入绝对路径 + 回车可扫描任意目录（`scope: any`）。
4. 用「分组 / 排序」下拉与升序/降序按钮调整视图；列表超过 200 条时点「显示更多」逐批展开。
5. 点击任意文件行打开**预览抽屉**（← 返回列表，头部按钮复制路径）；「自动刷新」默认开启，每 60 秒重扫（点击「刷新」立即重扫，并会取消进行中的扫描）。
6. 让 Agent 使用产物工具：直接说「列出当前工作区有哪些产物/代码文件」即可，DSH 会调用 `artifacts_list`。
7. 右上角「✕」或拖拽右栏边界收起；收起后点窗口右下角贴边的「📦 产物面板」标签重新打开。

## 开发

```sh
npm install --legacy-peer-deps   # peer 依赖由 DSH 宿主提供，跳过自动安装
npm test                         # node:test 单元测试（宿主纯函数 + 路由行为）
```

CI（GitHub Actions）会在 push / PR 时自动运行 `npm test`。

## 配置

宿主配置在 `cordis.patch.yml`（`dsh.profile.bundles` 装载后应用），常用项：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `scope` | `workspace` | `workspace` 只允许已注册工作区；`any` 允许任意目录 |
| `maxDepth` | `8` | 递归最大深度 |
| `maxFiles` | `5000` | 单次扫描最大文件数 |
| `maxLineFileSize` | `1048576` | 参与行数统计的单文件大小上限（字节） |
| `maxPreviewBytes` | `262144` | 预览抽屉单文件读取上限（字节），超出截断 |
| `skipDirs` | 见 patch | 按 basename 跳过的目录 |

在 profile 的 `cordis.patch.yml` 中覆盖：

```yaml
- id: artifacts-panel
  config:
    scope: any
    maxDepth: 10
    maxFiles: 10000
```

## 架构

- **宿主端**（`lib/index.js`）：Cordis 插件，向 `webServer` 注册 `POST /api/artifacts/scan`（递归扫描，返回纯元数据）
  与 `GET /api/artifacts/read`（有界读取单个文件供预览）；向 `tools` 注册 `artifacts_list` Agent 工具。
  三个入口共享同一套 scope 校验（已注册工作区边界）与安全默认，绝不回传大文件内容。
- **浏览器端**（`lib/client.js`）：`dsh.client` 客户端 bundle，面板注册进 `details` 插槽（右侧详情栏，
  priority -1），右下角触发标签注册进 `shell.overlay`；通过 `fetch` 调用宿主路由，
  分组、排序、过滤与分页全部在本地完成。

## 兼容性

- 目标平台：`web`（`dsh web`）。
- 依赖 DSH `0.1.0-rc.6` 的客户端插槽体系（`shell.overlay`、`locale`）与宿主 `webServer`、`tools` 服务。
